# Apprentissages

## modules

## Court résumé de l’objectif visé

on veux séparer les responsabilité et faire des modules qui se transmettent des données.
le 1er module créer les fichiers avec des noms aléatoire, et renvoie les noms des fichiers. le 2eme module exécute une commande pour chaque fichier créé

### Problème rencontré et pourquoi il est survenu
l'output du 1er module est une map, ce qui n'est pas très propre, on pourrait essayer de renvoyer un tableau d'une dimension plutôt.
### Solution appliquée et pourquoi cette solution fonctionne
je n'ai pas modifié par manque de temps ce paramètre.

### Ce que j'ai appris
les modules terraform permettent de séparer le code et de l'organiser. On peux séparer un modules en plusieurs fichiers standard, très utile pour les plus gros modules.
